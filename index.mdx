Tyto gives you sandboxed, remote compute environments — called **sandboxes** — that you can create, run commands in, transfer files to and from, and expose ports from.

Every sandbox is a full Linux VM you control over a REST API: create it from a template, run commands with buffered exec, a live TTY, or a named managed session, upload and download files over its filesystem API, and publish a running port as an HTTPS preview URL. Sandboxes suspend automatically when idle and resume on demand — there's no explicit start, stop, or wake to manage.

You can talk to Tyto directly over HTTPS, through the TypeScript, Python, or Go SDK, from the `tyto` CLI, or from any MCP-compatible client (Claude Desktop, Claude Code, Cursor, …) using the Tyto MCP server.
