---
title: Quickstart
description: Create a sandbox and run a command in under 5 minutes
---

This walks through the smallest possible loop: get a key, create a sandbox, run a command in it, clean up. Every example uses the `ubuntu-24.04` template — see [Templates](/concepts/templates) for what that means.

<Steps>
  <Step title="Get an API key">
    Install the CLI and log in — this opens a browser tab for you to approve, then hands the CLI a `byk_`-prefixed personal API key.

    <CodeGroup>
    ```shell Homebrew
    brew install bonyai/tap/tyto
    tyto login
    ```

    ```shell Install script
    curl -fsSL https://get.tyto.run/install.sh | sh
    tyto login
    ```
    </CodeGroup>

    See [Authentication](/authentication) for exactly what `tyto login` does under the hood, and how to mint a key without it. Once you have a key, export it — the CLI and every SDK read this variable by default:

    ```bash
    export BONYA_API_KEY=byk_...
    ```
  </Step>
  <Step title="Install an SDK (optional)">
    Skip this if you're only using the CLI or raw REST.

    <CodeGroup>
    ```bash TypeScript
    npm install @bonya-ai/tyto
    ```

    ```bash Python
    python -m pip install tyto.run
    ```

    ```bash Go
    go get github.com/bonyai/tyto-go
    ```
    </CodeGroup>
  </Step>
  <Step title="Create a sandbox">
    Every sandbox needs a `template_id`. `POST /v1/sandbox` returns `202` immediately by default, with the sandbox still `CREATING` — pass `?wait=ready` to block until it's up and get `201` back instead.

    <CodeGroup>
    ```shell cURL
    curl -s -X POST "https://api.tyto.run/v1/sandbox?wait=ready" \
      -H "Authorization: Bearer $BONYA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"template_id": "ubuntu-24.04"}'
    ```

    ```shell CLI
    tyto create --template ubuntu-24.04
    ```

    ```ts TypeScript
    import { Tyto } from "@bonya-ai/tyto";

    const client = new Tyto();
    const sandbox = await client.sandboxes.create({ template: "ubuntu-24.04" });
    console.log(sandbox.id);
    ```

    ```python Python
    from tyto import Tyto

    with Tyto() as client:
        sandbox = client.sandboxes.create(template="ubuntu-24.04")
        print(sandbox.id)
    ```

    ```go Go
    client, err := tyto.NewClient()
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    sandbox, err := client.Sandboxes.Create(ctx, "ubuntu-24.04")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(sandbox.ID)
    ```
    </CodeGroup>

    The response body is `{ "sandbox": { "sandbox_id": "...", "state": "RUNNING", "template_id": "ubuntu-24.04", ... } }`. See [Sandboxes](/concepts/sandboxes) for the full lifecycle.
  </Step>
  <Step title="Run a command">
    The simplest way to run something is buffered exec — one JSON request, one JSON response, no WebSocket involved. A non-zero exit code is still a `200`; check `exit_code` in the body.

    <CodeGroup>
    ```shell cURL
    curl -s -X POST "https://api.tyto.run/v1/sandbox/$SANDBOX_ID/exec" \
      -H "Authorization: Bearer $BONYA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"cmd": ["echo", "hello from tyto"]}'
    ```

    ```shell CLI
    tyto exec $SANDBOX_ID -- echo "hello from tyto"
    ```

    ```ts TypeScript
    const result = await sandbox.exec(["echo", "hello from tyto"]);
    console.log(result.stdout, result.exitCode);
    ```

    ```python Python
    result = sandbox.exec(["echo", "hello from tyto"])
    print(result.stdout, result.exit_code)
    ```

    ```go Go
    result, err := sandbox.Exec(ctx, []string{"echo", "hello from tyto"})
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(result.Stdout(), result.ExitCode)
    ```
    </CodeGroup>

    That's one of three ways to run a command — see [Run a command](/guides/run-a-command) for the WebSocket TTY and managed-session modes, which are what you want for interactive shells or long-running processes.
  </Step>
  <Step title="Clean up">
    Deletion is a synchronous teardown — the call doesn't return until the sandbox is gone.

    <CodeGroup>
    ```shell cURL
    curl -s -X DELETE "https://api.tyto.run/v1/sandbox/$SANDBOX_ID" \
      -H "Authorization: Bearer $BONYA_API_KEY"
    ```

    ```shell CLI
    tyto delete $SANDBOX_ID
    ```

    ```ts TypeScript
    await sandbox.delete();
    ```

    ```python Python
    sandbox.delete()
    ```

    ```go Go
    sandbox.Delete(ctx)
    ```
    </CodeGroup>
  </Step>
</Steps>
