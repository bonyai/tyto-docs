## `tyto snapshot`

<Info>Alias: `snap`</Info>

Snapshots capture a running sandbox's state. Creating one requires the source sandbox to be **running** — suspended, failed, and deleted sandboxes are all rejected.

<Note>
There is no `snapshot list` command. `tyto snapshot` only supports `create` and `delete`.
</Note>

## `create`

Creates a snapshot from a running sandbox.

```shell
tyto snapshot create [sandbox]
```

| Flag | Default | Description |
| --- | --- | --- |
| `--idempotency-key` | — | Idempotency key for the snapshot create request. |
| `--by-name` | `false` | Treat the sandbox argument as a name even if it looks like an id. |

```shell
tyto snapshot create web
```

## `delete`

Deletes a snapshot.

```shell
tyto snapshot delete [sandbox] <snapshot-id>
```

```shell
tyto snapshot delete web snap-a1b2c3
```

| Flag | Default | Description |
| --- | --- | --- |
| `--by-name` | `false` | Treat the sandbox argument as a name even if it looks like an id. |
