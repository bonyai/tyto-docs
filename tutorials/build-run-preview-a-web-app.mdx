Get a small web app running inside a sandbox and reachable at a public preview URL — entirely from the `tyto` CLI. Every command below uses the `bonya-dev` template. If you haven't installed the CLI or logged in yet, start with the [Quickstart](/quickstart).

<Steps>
  <Step title="Create a sandbox">
    ```shell
    tyto create web --template bonya-dev
    ```

  <Step title="Checkpoint before installing anything">
    Snapshots here are one-way checkpoints — there's no `restore` or `list` command in the CLI today (see [Snapshots](/concepts/snapshots)). Treat the id below as an insurance policy you'd manually rebuild from — a fresh sandbox plus reapplying your changes — not a one-command rollback.

    ```shell
    tyto snapshot create web
    ```

  <Step title="Make a workspace directory">
    ```shell
    tyto fs mkdir web /workspace/app
    ```

  <Step title="Upload the app as a tarball">
    `fs upload` moves exactly one file's raw bytes per call — there's no directory upload (see [Files](/concepts/files)). Package the project locally first, then upload the single archive:

    ```shell
    tar czf app.tar.gz -C my-app .
    tyto fs upload web ./app.tar.gz /workspace/app.tar.gz
    ```

    <TerminalOutput lines={[
      [{text: "Uploaded ./app.tar.gz to /workspace/app.tar.gz", color: "#626262"}],
    ]} />
  </Step>

  <Step title="Extract it on the sandbox">
    ```shell
    tyto exec web -- tar xzf /workspace/app.tar.gz -C /workspace/app
    ```

    `tar` prints nothing on success. Confirm the files landed:

    ```shell
    tyto fs ls web /workspace/app
    ```

  <Step title="Check for a language runtime before assuming it's there">
    Nothing guarantees a Node runtime is preinstalled on every template (see [Templates](/concepts/templates)) — check first, and only proceed with `npm install` if it succeeds. `bonya-dev` does include Node:

    ```shell
    tyto exec web -- node --version
    ```

    ]} />
  </Step>

  <Step title="Install dependencies">
    ```shell
    tyto exec web --cwd /workspace/app -- npm install
    ```

    <TerminalOutput lines={[
      [{text: "up to date, audited 1 package in 170ms"}],

      [{text: "found 0 vulnerabilities"}],
    ]} />
  </Step>

  <Step title="Start the dev server in a managed session">
    A managed session keeps the process running after your terminal disconnects — unlike `exec`, which ends when the connection does (see [Sessions](/concepts/sessions)). `session create` has no `--cwd` flag, so `cd` inside the command itself:

    ```shell
    tyto session create web dev -- sh -c 'cd /workspace/app && npm run dev'
    ```

  <Step title="Publish a preview URL">
    ```shell
    tyto preview create web 3000 --name app
    ```

    `token` is the default auth mode — the URL alone isn't enough to reach it; see [Previews](/concepts/previews) for the token exchange. Passing `--auth public` would skip that, at the cost of anyone with the URL being able to reach it.
  </Step>

  <Step title="Watch it running">
    ```shell
    tyto session attach web dev
    ```

  <Step title="Clean up">
    Tear down what this page created, in reverse order:

    ```shell
    tyto preview delete web pv-4j25exovxnccyjqpcgpnbpoiue
    tyto session kill web dev
    tyto snapshot delete web snp-92670f726baeaa8e4fbf926c73150fe8
    tyto delete web --force
    ```
